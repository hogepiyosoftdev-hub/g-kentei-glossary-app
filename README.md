# G検定 完全単語帳 Webアプリ（全721語・リアルタイムカード検索）

`g_kentei_glossary.md`（第10版・全721語・延べ3,641ポイントキーワード・付録混同比較早見表53テーマ）をブラウザ上で快適に閲覧・リアルタイム検索できるカード型Webアプリです。

## 主な機能
- **リアルタイム追従インクリメンタル検索**: 1文字入力するたびに即座にカード一覧を更新（例：`C` → `CN` → `CNN`）。関連度ランキング（完全一致 → 前方一致 → 見出し一致 → ポイントキーワード一致 → 解説・混同注意一致）、AND検索（スペース区切り）、大文字/小文字・全角/半角・ひらがな/カタカナ自動吸収、一致箇所ハイライト（`<mark>`）対応。
- **カード型管理 & 詳細モーダル**: 各語をカード（見出し・別名・章タグ・ポイントキーワード・定義抜粋）で一覧表示し、クリックで全セクション（ポイントキーワード / 定義・意味 / 主な特徴 / 関連ワード・試験ポイント / 混同注意）＋KaTeX数式表示を展開。「全文リスト表示」への切替も可能。
- **学習支援機能**: 要復習ブックマーク（★）・習得済みチェック（✓）・進捗バー（ブラウザの `localStorage` に自動保存）、暗記モード（定義をぼかして見出し＋キーワードで確認）、章フィルタ・検索対象フィルタ、混同比較早見表（53テーマ）リアルタイム検索、ダークモード対応。

## 起動方法
1. **そのままブラウザで開く（サーバ不要）**: `index.html` を Chrome / Edge 等で直接開くだけで動作します。
2. **ローカルサーバで起動する**:
   ```powershell
   cd C:\Users\Admin\.gemini\antigravity\scratch\g-kentei-glossary-app
   python -m http.server 8765
   ```
   ブラウザで `http://localhost:8765` を開いてください。

## 辞書データの再生成
元の `g_kentei_glossary.md` を更新した場合は、以下で `data/glossary-data.js` / `data/glossary-data.json` を再生成できます：
```powershell
python scripts/build_data.py
```
